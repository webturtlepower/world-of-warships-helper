## 🧩 About

**World of Warships Helper** is a comprehensive companion overlay for World of Warships featuring a battle HUD overlay, ship stats viewer, port quick-menu, salvo timer, minimap pings, and match log export.

Based on popular community tools like **WoWS Info**, **ModStation-style overlays**, and **open-source battle HUDs**.

---

## ✨ Features

### 🎮 Core HUD
- Battle Overlay — live ship stats, HP, and speed readout
- Salvo Timer — track reload cycles for main battery
- Minimap Pings — quick tactical markers on the minimap
- Damage Counter — running total per match
- Match Log Export — save battle summaries to file

### 🚢 Ship & Port Tools
- Ship Stats Viewer — armor, penetration, and shell data
- Port Quick-Menu — fast access to ships and loadouts
- Captain Skill Reference — browse skill builds in-game
- Module Compare — side-by-side upgrade stats

### 🏋️ Practice & Training
- Aim Reticle Overlay — improved lead indicator view
- Consumable Tracker — cooldown timers for consumables
- Detected Indicator — clear visibility of spotting status
- Replay Bookmarks — flag key moments in replays
